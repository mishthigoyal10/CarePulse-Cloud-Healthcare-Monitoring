How cloud storage is used

Patient profiles are stored in the patients collection. Each patient's vital-sign history is stored in that patient's readings subcollection. The dashboard reads updates from Firestore in real time.

Firestore access is restricted by Firebase Authentication custom roles and patient-to-account mapping. This is an academic prototype; a real healthcare deployment would also require audit logging, privacy controls and regulatory review.
